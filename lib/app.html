    Quick start (written)

    1. Onboard a key. Paste your NVIDIA NIM key in Onboard · API Key and Save. It is written to .env locally, never committed.
    2. Create an agent. In Add Agent pick id, division, role and brain; keep autonomous armed so it patrols on its cadence.
    3. Command the crew. Choose an agent and send a free prompt; the answer lands in the response panel.
    4. Shape persona with plugins. Open Plugins, pick an agent, toggle skill packs ON. Packs only adjust persona; no third-party code runs.
    5. Anchor memory on-chain. Keep Memory in hybrid mode; each ask anchors a hash to Sepolia. Click last tx to verify on Etherscan.
    6. Read telemetry. The top panel shows crew KPIs, state distribution, per-division/role load and activity volume.
    7. Tune in Settings. Set recall depth (how many recent memories an agent sees) and pick the accent color.
